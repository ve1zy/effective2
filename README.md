# LocalLibrary

Это учебный проект для создания веб-сайта библиотеки с использованием Express, Node.js и MongoDB.

## Возможности
- Операции CRUD для книг, авторов, жанров и экземпляров книг.
- Интеграция с MongoDB через Mongoose.
- Использование шаблонизатора Pug для представлений.

## Установка
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/username/LocalLibrary.git 
   ```
2. Установите зависимости:
	```bash
   	npm install
   	```
3. Запустите скрипт наполнения базы данных:
	```bash
   	node populatedb.js
   	```
4. Запустите сервер:
	```bash
   	npm start
   	```
## Как использовать
После запуска сервера перейдите по адресу http://localhost:3000, чтобы увидеть приложение.
База данных будет автоматически заполнена тестовыми данными после выполнения populatedb.js.
## Структура проекта
models/: Содержит модели данных (авторы, книги, жанры и т.д.).	
routes/: Маршруты приложения.
views/: Шаблоны Pug для отображения страниц.
public/: Статические файлы (стили, изображения и т.д.).
app.js: Основной файл приложения.
populatedb.js: Скрипт для наполнения базы данных тестовыми данными.
