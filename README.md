# LocalLibrary

Это учебный проект для создания веб-сайта библиотеки с использованием Express, Node.js и MongoDB.

## Возможности
- Операции CRUD для книг, авторов, жанров и экземпляров книг.
- Интеграция с MongoDB через Mongoose.
- Использование шаблонизатора Pug для представлений.

## Установка
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/username/LocalLibrary.git 
   ```
2. Установите зависимости:
	```bash
   	npm install
   	```
3. Запустите скрипт наполнения базы данных:
	```bash
   	node populatedb.js
   	```
4. Запустите сервер:
	```bash
   	npm start
   	```
## Как использовать
1. После запуска сервера перейдите по адресу http://localhost:3000, чтобы увидеть приложение.
2. База данных будет автоматически заполнена тестовыми данными после выполнения populatedb.js.
## Структура проекта
1. models/: Содержит модели данных (авторы, книги, жанры и т.д.).	
2. routes/: Маршруты приложения.
3. views/: Шаблоны Pug для отображения страниц.
4. public/: Статические файлы (стили, изображения и т.д.).
5. app.js: Основной файл приложения.
6. populatedb.js: Скрипт для наполнения базы данных тестовыми данными.
